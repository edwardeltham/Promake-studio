# Promake Studio website

Static site for Promake Studio: "We are weird and mad so you can look good."

- `index.html` holds the whole site. Views (Home, Work, Studio, Playground, Blog) switch with the URL hash, e.g. `#work`.
- `assets/` holds the logo, case-study images taken from the company profile, and client logos.

Open `index.html` in a browser to preview. To host it free, enable GitHub Pages on the `main` branch (Settings → Pages).

Client stories, blog posts and client names live in the `STORIES`, `POSTS` and `CLIENTS` arrays near the top of the script in `index.html`.
